4. SCROLL-TRIGGERED FADE-IN FOR ALL PAGE SECTIONS
   --------------------------------------------------
   Currently everything fades up on load using CSS animation + delay.
   That's fine for a single-page countdown, but if you ever add sections
   below (gallery, notes, etc.) you'll want elements to fade in only when
   the user scrolls to them, not all at once.

   Use an IntersectionObserver (like you already do for videos in the
   original site) to add a ".visible" class that triggers a CSS fadeUp:

       const observer = new IntersectionObserver((entries) => {
         entries.forEach(e => {
           if (e.isIntersecting) e.target.classList.add('visible');
         });
       }, { threshold: 0.15 });
       document.querySelectorAll('.reveal').forEach(el => observer.observe(el));

   Add class="reveal" to any element you want to animate on scroll.

   EFFORT: ★★☆☆☆ (15 min) | IMPACT: ★★★☆☆


5. SPARKLE TRAIL THAT FOLLOWS THE MOUSE CURSOR

   On desktop, as the user moves their mouse, tiny sparkle emojis (✨💫⭐)

   and memorable — feels like the page is enchanted.

   In script.js:

         spark.textContent = ['✨','💫','⭐','🌟'][Math.floor(Math.random()*4)];

6. SMOOTH CARD TILT ON MOUSE HOVER (3D PARALLAX)
   --------------------------------------------------
   When the user hovers over the glassmorphism countdown cards, they
   subtly tilt in 3D towards the cursor — like a holographic card.
   This is achieved with a mousemove event + CSS transform: rotateX/Y.

   In script.js:
       document.querySelectorAll('.count-card').forEach(card => {
         card.addEventListener('mousemove', (e) => {
           const rect = card.getBoundingClientRect();
           const x = (e.clientX - rect.left) / rect.width  - 0.5;  // -0.5 to 0.5
           const y = (e.clientY - rect.top)  / rect.height - 0.5;
           card.style.transform = `perspective(600px)
                                   rotateY(${x * 15}deg)
                                   rotateX(${-y * 15}deg)
                                   scale(1.04)`;
         });
         card.addEventListener('mouseleave', () => {
           card.style.transform = '';
         });
       });

   The result looks like each card is a physical hologram that reacts
   to where your hand is pointing. Stunning on desktop.

   EFFORT: ★★☆☆☆ (20 min) | IMPACT: ★★★★★


7. A SOFT ENTRANCE ANIMATION FOR THE PROGRESS BAR
   ---------------------------------------------------
   The progress bar at the top is good but it just snaps to its filled
   position on page load. A better approach: start it at 0% width, then
   animate to the real percentage over ~1.5 seconds on page load. This
   gives it a satisfying "filling up" effect right as the page opens.

   In script.js, change updateProgress() to use a timed fill on first run:
       let firstRun = true;
       function updateProgress() {
         // ... calculate pct as before ...
         if (firstRun) {
           progressFill.style.width = '0%';
           requestAnimationFrame(() => {
             setTimeout(() => {
               progressFill.style.transition = 'width 1.5s cubic-bezier(.4,0,.2,1)';
               progressFill.style.width = `${pct}%`;
             }, 400);
           });
           firstRun = false;
         } else {
           progressFill.style.width = `${pct}%`;
         }
       }

   EFFORT: ★★☆☆☆ (15 min) | IMPACT: ★★★☆☆

11. CONFETTI / FIREWORKS WHEN THE PROGRESS BAR REACHES 100%
    ----------------------------------------------------------
    When the countdown hits zero and the celebration triggers, you already
    fire confetti — which is great. But you could add a fireworks pattern
    on a loop (like the wax-seal version had) to make the celebration feel
    more sustained and theatrical.

    Add a launchFireworks() function alongside celebrate():
        function launchFireworks(duration = 8000) {
          const end = Date.now() + duration;
          const defaults = { startVelocity: 30, spread: 360, ticks: 80, zIndex: 9999 };
          function fire() {
            const timeLeft = end - Date.now();
            if (timeLeft <= 0) return;
            const count = 55 * (timeLeft / duration);
            confetti(Object.assign({}, defaults, {
              particleCount: count,
              colors: PALETTE,
              shapes: ['star','circle'],
              origin: { x: Math.random() * 0.7 + 0.15, y: Math.random() * 0.4 + 0.1 }
            }));
            setTimeout(fire, 400);
          }
          fire();
        }

    Then call launchFireworks(8000) inside celebrate() after the initial bursts.

    EFFORT: ★★☆☆☆ (20 min) | IMPACT: ★★★★☆
